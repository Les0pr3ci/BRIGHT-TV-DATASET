# BRIGHT-TV-DATASET
Bright TV Viewership Project – README

Project Overview

The Bright TV Viewership Project was conducted to analyse customer viewing behaviour by combining two datasets:

* User Profile Dataset – containing customer demographic and subscription information.
* Viewership Dataset – containing records of viewing activity, channels watched, watch duration, and viewing patterns.

By integrating these datasets, we were able to generate meaningful insights that support data-driven decision-making for Bright TV.

⸻

Project Objective

The main objective of this project was to understand customer viewing habits and identify trends that can help Bright TV improve customer engagement, optimise content offerings, and make informed business decisions.

⸻

Datasets Used

1. User Profile Dataset

This dataset contains information about Bright TV subscribers, including:

* User ID
* Age
* Gender
* Location
* Subscription Type
* Registration Date

2. Viewership Dataset

This dataset contains customer viewing activity, including:

* User ID
* Channel Watched
* Watch Duration
* Viewing Date
* Viewing Time


The two datasets were linked using the User ID, allowing customer profiles to be analysed alongside their viewing behaviour.

⸻

Data Preparation

Before performing the analysis, the datasets were cleaned and prepared by:

* Handling missing values
* Removing duplicate records
* Standardising data formats
* Verifying data consistency
* Joining the User Profile and Viewership datasets using the User ID

⸻

Analysis Performed

The project explored several key business questions, including:

* Which subscription plans have the highest engagement?
* Which channels are watched the most?
* Which age groups spend the most time watching TV?
* How viewing behaviour differs by gender and location.
* Peak viewing periods.
* Overall customer engagement trends.

SQL queries were used to retrieve and aggregate data, enabling meaningful analysis and reporting.

⸻

Key Insights

The combined analysis of the User Profile and Viewership datasets enabled us to generate actionable insights, including:

* Identification of the most popular channels among subscribers.
* Recognition of customer segments with the highest viewing activity.
* Understanding how demographics influence viewing behaviour.
* Discovery of peak viewing times that can inform content scheduling.
* Identification of subscription plans with higher customer engagement.
* Insights into device preferences, helping guide platform optimisation.

These findings allow Bright TV to make evidence-based decisions that improve customer satisfaction and support business growth.

⸻

Business Value

The insights generated from this project can assist Bright TV in:

* Improving content recommendations.
* Enhancing customer retention strategies.
* Developing targeted marketing campaigns.
* Optimising programming schedules.
* Supporting strategic business decisions through data analytics.

Conclusion

The Bright TV Viewership Project demonstrates how integrating user profile information with viewership data can uncover valuable patterns in customer behaviour. Rather than analysing each dataset independently, combining them provided richer insights that support informed decision-making. This project highlights the importance of data integration, cleaning, and analytical techniques in transforming raw data into actionable business intelligence.
